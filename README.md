# Консультация по планированию

Полностью статичный landing page без фреймворков и сборщика.

## Файлы

- `index.html` — разметка;
- `styles.css` — стили и адаптив;
- `script.js` — меню, FAQ, CTA, видео и конфигурация ссылок;
- `assets/` — изображения сайта.

Откройте `index.html` в браузере или загрузите содержимое папки на любой статический хостинг, включая Vercel.

Перед публикацией добавьте реальные ссылки в объект `config` в `script.js`.
